# Вредно-полезно

Локальная браузерная игра для детского сенсорного стола. Профили, результаты и
лидерборд хранятся в IndexedDB выбранного браузерного профиля. Интернет во время
игры не используется.

## Запуск на Mac

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000` в Chrome. Для проверки в полном
экране можно использовать штатный kiosk-режим браузера.

## Игровой сценарий

- ребёнок создаёт профиль: имя или псевдоним и значок;
- после выбора игрока доступны три уровня сложности по 20 продуктов;
- на первом уровне продукты очевидны, на втором встречаются продукты-обманки,
  на третьем сравниваются способы приготовления и блюда фастфуда;
- продукт можно перетащить или положить касанием по выбранной зоне;
- после ответа объяснение остаётся на экране 2,4 секунды и добавляется в
  боковую ленту фактов;
- результат сохраняется в локальную статистику и лидерборд;
- рейтинг сравнивает лучший результат каждого игрока отдельно по уровням.

## Варианты оформления

На стартовом экране переключатель «Стиль» меняет весь визуальный мир игры:
«Поляна», «Лес» или «Космос». Выбранное оформление сохраняется в браузере и
восстанавливается при следующем запуске. Все иллюстрации находятся внутри
проекта, поэтому переключение и дальнейшая игра работают без интернета.

Все 60 продуктов представлены отдельными отрисованными объектами на прозрачном
фоне и хранятся внутри проекта. Если отдельный файл окажется недоступен,
интерфейс сможет использовать соответствующий эмодзи как резервный вариант.

## Взрослый раздел

Нажмите кнопку «Вход для взрослых» на экране выбора игрока и введите PIN.
PIN: `5553`. В разделе доступны сводная статистика, таблица лучших результатов
всех игроков по уровням, список сложных продуктов и экспорт JSON.

## Локальные данные

Данные привязаны к конкретному столу, браузеру и его профилю. Очистка данных
сайта удалит игровые профили и результаты, поэтому перед обслуживанием стола
следует сделать экспорт. Результаты с разных столов автоматически не объединяются.


## Развёртывание на VPS

Проект включает Docker Compose для существующей сети `proxy`, шаблон server
block общего nginx и готовый шаблон GitHub Actions. После первичной настройки
VPS workflow активируется, и каждый push в ветку `main` автоматически обновляет
приложение. Пошаговая инструкция находится в
[`deploy/README.md`](deploy/README.md).
